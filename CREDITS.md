# Credits

grapeGram — производный клиент. Вся заслуга за базовую функциональность
принадлежит авторам upstream-проектов. Авторы upstream **не поддерживают**
grapeGram и не связаны с ним.

## Cherrygram
- Автор: @Cherrygram
- https://github.com/arsLan4k1390/Cherrygram
- Лицензия: GPL-2.0
- Вклад: настройки оформления и чатов, иконки приложения, камера, бэкапы
  настроек, нижние вкладки, меню сообщений, приватность.
- Ключевые пути: `TMessagesProj/src/main/java/uz/unnarsx/cherrygram/`
  (`core/configs/`, `preferences/`, `camera/`).

## exteraGram
- Автор: @exteraGram
- https://github.com/exteraSquad/exteraGram
- Лицензия: GPL-3.0
- Вклад: Plugin SDK, Python runtime (Chaquopy), хуки, DEX-плагины, каталог
  плагинов, инструменты разработчика.
- Ключевые пути: `TMessagesProj/src/{main,full,lite}/java/com/exteragram/messenger/plugins/`.
