# Авторы, upstream и лицензии

grapeGram — производный клиент, собранный поверх закреплённой версии exteraless.
Авторы upstream-проектов не поддерживают grapeGram и не связаны с ним.

## Cherrygram

- Автор / канал: [@Cherrygram](https://t.me/Cherrygram)
- GitHub: https://github.com/arsLan4k1390/Cherrygram
- Лицензия репозитория: GNU GPL-2.0 (см. upstream `LICENSE`)
- Использование в grapeGram: 18 вариантов launcher-иконок и визуальный референс
  для индивидуальных цветов и частиц бейджей. В исходниках Cherrygram также
  сохранены авторские заголовки и условия лицензирования.

## exteraGram

- Автор / канал: [@exteraGram](https://t.me/exteraGram)
- GitHub: https://github.com/exteraSquad/exteraGram
- Лицензия: GNU GPL-3.0 (см. upstream `LICENSE`)
- Использование: upstream-механизмы плагинов, Python runtime / Chaquopy,
  SDK, хуки и связанные интерфейсы; 31 вариант launcher-иконок.

## exteraless

- Автор / канал: [@exteraless](https://t.me/exteraless)
- GitHub: https://github.com/exteraless/exteraless
- Лицензия: GNU GPL-3.0 (см. upstream `LICENSE`)
- Использование: закреплённая базовая версия клиента, настройки, плагины,
  разрешения, AI, AyuMoments и интегрированные upstream-компоненты.

## Лицензия grapeGram

Исходники grapeGram распространяются под GNU GPL-3.0. Отдельные upstream-ресурсы
и сторонние компоненты сохраняют собственные лицензии и уведомления. Для
производных сборок необходимо сохранять соответствующие copyright notices,
лицензионные тексты и сведения об изменениях.
