# Тестирование

## Автоматически (в этом репо, прогоняется здесь)

```bash
python3 -m unittest discover -s tests -v
```

Покрыто:

- схемы `owner_users.json` / `badge_users.json` (поля, типы, ровно 2 владельца);
- канонизация JSON и Ed25519 подпись/проверка (openssl);
- подделка подписи → INVALID;
- изменение JSON после подписи → INVALID;
- одноразовость challenge и TTL;
- отказ не-владельцу в `grant`;
- откат версии запрещён;
- отсутствие приватного ключа в репозитории;
- 9 иконок, имена уникальны, RGBA, прозрачные углы.

## Вручную (только на устройстве / в CI)

Клиент: запуск, вход, отправка/приём, медиа, 2 аккаунта, уведомления,
звонки. Настройки: grapeGram первым, остальное на местах. Иконки: оба входа,
синхронизация, перезапуск. Плагины: установка, разрешения, отказ, просмотр
исходников, AI, журнал, защита от падений, Python/DEX. Бейджи: выдача,
отзыв, подпись, кэш, офлайн. Производительность: Macrobenchmark, JankStats,
Perfetto — до/после.

Непроведённые пункты помечаются как непроведённые, без «успешно».
