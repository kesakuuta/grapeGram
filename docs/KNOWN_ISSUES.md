# Известные ограничения и проблемы

1. **Клиент не собран в этом окружении.** Нет JDK/SDK/NDK, 0.9 ГБ диска,
   `/storage/emulated/0` не смонтирован. Сборка — только GitHub Actions.
2. **Исходники форков не склонированы** (~2 ГБ). Карта функций построена по
   деревьям репозиториев (реальные пути), но не по полному коду.
3. **Ключ подписи демонстрационный.** Приватный ключ выдан отдельно и не
   входит в репозиторий; для продакшена сгенерируйте новый и положите в
   `GRP_SIGNING_KEY_PEM`.
4. **Сервер выдачи** — референсная реализация на stdlib; требует HTTPS,
   постоянного хранилища и настроенного вебхука бота.
5. **Бейдж — локальная визуальная метка.** Он не является Telegram Premium и
   не изменяет данные на серверах Telegram.
6. **AI-анализ** требует настроенного провайдера; без него кнопка честно
   недоступна.
7. **Rust-модули** не собраны (нет Rust toolchain в контейнере); описаны и
   запланированы.
8. **Производительность** не измерена — нет устройства/профилировщика в этом
   окружении.
