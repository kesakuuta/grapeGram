## Обязательства grapeGram

1. Итоговый клиент распространяется под **GPL-3.0**.
2. Сохраняются copyright-уведомления всех upstream-проектов.
3. Исходники производного клиента публичны.
4. `CREDITS.md` явно указывает авторов и то, что они не поддерживают grapeGram.
5. Сторонние библиотеки — с их лицензиями (см. `docs/THIRD_PARTY.md` при сборке).

## Данные бейджей

`data/*.json` — публичные данные проекта, не содержат персональной
информации (только Telegram ID, тип бейджа, даты).
