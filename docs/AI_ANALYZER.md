# AI-анализатор плагинов

Опирается на существующую AI-службу exteraless (`app/exteraless/ai/`):
`AiController`, `ai/network/Client.java`, `ai/data/*`. Дублирующая система не
создаётся — добавляется инструмент «анализ плагина».

## Что анализируется (реальные файлы, не описание)

1. Распаковка архива в песочницу, список файлов, дерево, поиск.
2. Манифест: `id`, автор, версия, заявленные разрешения.
3. Python: импорты, вызовы `requests/urllib/socket`, `open`, `os.system`,
   `eval/exec`, `__import__`, работа с `sys.modules`, хуки.
4. DEX: строки, имена классов/методов, ссылки на сетевые и файловые API
   (через `PluginCapabilityScan`, ключи `obfuscation`, `dex`, `DexInfo`).
5. Нативные `.so`: наличие, архитектуры, подозрительные символы.
6. Адреса: URL, домены, IP.
7. Расхождения: заявленные разрешения vs реально используемые API.

## Ответ ИИ

- ссылки на файл и строку/фрагмент;
- оценка риска (низкий/средний/высокий) с обоснованием;
- явная оговорка: статический анализ не гарантирует безопасность;
- «не определено», если данных недостаточно — без выдумок.

## Приватность

В модель отправляются только файлы плагина и вопрос. Ключи API — в
настройках пользователя, не в репозитории. Локальный режим: если провайдер
не настроен, анализ недоступен, а не имитируется.
